Instala o painel de afiliado (comissão 10 %), torneios/campeonatos por moderadores, destaque no marketplace e verificação de vendedores.
Antes: o módulo competitivo (sql-competitivo.html) já tem de estar instalado.
Abre o SQL Editor do Supabase. Para cada parte, por ordem:
1. Toca em "Copiar parte N".
2. No SQL Editor apaga o que lá estiver, cola e toca em Run.
3. Espera "Success" e passa à seguinte.
Se aparecer um aviso sobre operações destrutivas, confirma: o script é seguro e pode repetir-se.
