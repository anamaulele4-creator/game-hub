GAME HUB no teu ecrã principal

Abre num toque, ocupa menos de 1 MB, funciona offline e recebe notificações de lives.

No Android abre no Chrome e usa ⋮ › Instalar app. No computador, o ícone de instalar aparece na barra de endereço.

🤖 Android (Chrome)

  1. Abre o site no Chrome.
  2. Toca em Instalar app (ou ⋮ › Instalar app / Adicionar ao ecrã principal).
  3. Confirma. O ícone aparece com as tuas apps.

🍎 iPhone / iPad (Safari)

  1. Abre este site no Safari.
  2. Toca no botão Partilhar (quadrado com seta ↑).
  3. Escolhe Adicionar ao ecrã principal.
  4. Toca em Adicionar. O GAME HUB aparece como app.

No iPhone, as notificações push só funcionam depois de instalar (iOS 16.4+).
