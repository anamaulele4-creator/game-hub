TXAPILOG · Reconciliação de depósitos

Faz o crédito dos depósitos M-Pesa/e-Mola (ClicPay) a cada 2 minutos, mesmo com a /carteira fechada. Antes: o módulo competitivo (sql-competitivo.html) já tem de estar instalado.

No SQL Editor apaga o que estiver, cola e toca em Run. Se aparecer aviso, confirma: é seguro e pode repetir-se.

Depois, um único passo:

  1. No SQL Editor corre: select decrypted_secret from vault.decrypted_secrets where name = 'reconcile_secret';
  2. Copia o valor e cola-o em Supabase → Edge Functions → Secrets → RECONCILE_SECRET.
