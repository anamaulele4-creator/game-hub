TXAPZONE

TXAPZONE no teu telemóvel

Abre num toque, funciona com rede fraca e recebe alertas de torneios e recargas. Menos de 1 MB.

Instalação direta do navegador (PWA) ou pelo APK Android. Sem loja.

Android

  1. Abre este site no Chrome.
  2. Toca em Instalar TXAPZONE (no topo) ou ⋮ › Instalar app / Adicionar ao ecrã principal.
  3. Confirma. O ícone aparece com as tuas apps.

APK para Android

Se o Chrome não mostra "Instalar app", instala o APK oficial (versão 1.0.0).

Baixar APK (Android)
  1. Baixa o ficheiro txapilog.apk.
  2. Abre o ficheiro (nas notificações ou na pasta Transferências).
  3. Se pedir, permite "Instalar apps desconhecidas" para o Chrome / Ficheiros.
  4. Toca em Instalar. A TXAPZONE aparece com as tuas apps.

iPhone / iPad

  1. Abre este site no Safari.
  2. Toca no botão Partilhar (quadrado com seta ↑).
  3. Escolhe Adicionar ao ecrã principal.
  4. Toca em Adicionar. A TXAPZONE aparece como app.

As notificações push no iPhone funcionam depois de adicionar ao ecrã principal (iOS 16.4+).
